# Guia de Instalação no macOS — BiblioGest

Este guia explica como instalar e utilizar o **BiblioGest** em ambiente macOS utilizando a imagem `BiblioGest.dmg`.

---

## Passo 1: Download e Montagem
1. Baixe o arquivo `BiblioGest.dmg`.
2. Clique duas vezes para abrir a imagem de disco.

## Passo 2: Instalação
Arraste o ícone do **BiblioGest** para a pasta **Aplicativos (Applications)**.

## Passo 3: Execução
1. Abra o **BiblioGest** na pasta Aplicativos.
2. O aplicativo iniciará o launcher e disponibilizará o sistema em `http://localhost:3000`.
