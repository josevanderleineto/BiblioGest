# Guia de Instalação no Windows — BiblioGest

Este guia explica como instalar e utilizar o **BiblioGest** em ambiente Windows utilizando o instalador automático desktop `BiblioGest-Setup.exe`.

---

## Passo 1: Download do Instalador
Baixe o instalador oficial `BiblioGest-Setup.exe`.

## Passo 2: Execução
1. Clique duas vezes no arquivo `BiblioGest-Setup.exe`.
2. O assistente instalará o aplicativo e criará um atalho na Área de Trabalho e no Menu Iniciar.

## Passo 3: Inicialização do Sistema
1. Abra o aplicativo **BiblioGest**.
2. O aplicativo iniciará automaticamente os serviços locais e verificará o banco de dados PostgreSQL.
3. Clique no botão **"Abrir BiblioGest"** ou aguarde a abertura automática do navegador em `http://localhost:3000`.

## Primeiro Login
- **Usuário**: `admin`
- **Senha**: `admin`
- Altere a senha inicial no primeiro acesso.
